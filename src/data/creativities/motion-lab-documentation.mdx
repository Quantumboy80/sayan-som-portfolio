# MOTION LAB - Technical & Architectural Documentation

Welcome to the official developer documentation for **MOTION LAB** (formerly TOONHUB), a premium, motion-heavy landing page built in React, TypeScript, and Tailwind CSS. This showcase integrates custom scroll timelines, interactive blueprints, and custom cursor-following video portals.

---

## 🏗️ How This Project Was Built

The project was constructed following a modular, performance-oriented workflow:
1. **Scaffolding**: Created a modern React 19 + TypeScript template using Vite for instant building and compilation.
2. **Styling Integration**: Configured Tailwind CSS v4 in `vite.config.ts` and `src/index.css`, establishing a robust layout coordinate grid (`.grid-bg`) and standard keyframe systems.
3. **Scroll Timeline Architecture**: Built a native window-scroll listener that updates the scroll state (`scrollY`), mapping scroll depths to normalized ranges (`0.0` to `1.0`) to avoid heavy third-party scroll libraries.
4. **Section Assembly**:
   - **Hero Carousel**: An interactive carousel featuring character figurines that morph position on scroll.
   - **Anatomy Specs**: Hotspots that project dotted connector blueprints matching active spec cards.
   - **Horizontal Gallery**: A custom `400vw` slider that translates horizontally while vertical scrolling is pinned, holding the final blue variant on-screen.
   - **Expanding Video Portal**: A local screen recording video that enlarges from a card to a full-screen layout.
   - **Interactive Play/Pause**: A cursor follower button that replaces the default browser mouse pointer inside the video block.
   - **Creative Lab & Pre-order Footer**: A layout equipped with magnetic CTA buttons and sliding link animations.

## 🎨 Design Principles

1. **Ambient Dark Mode Grid**: Uses `#0b0c10` (core dark) layered with an active dotted background grid and grain film overlays to create depth.
2. **Fluid Colorways**: Employs high-contrast HSL character background panels (Rusty Clay, Shinto Green, Pink Beat, Neo Sky) that transition as the user scrolls.
3. **Winding Guidelines**: Utilizes a thin, semi-translucent white SVG curve (`stroke="rgba(255,255,255,0.18)"`) running down the right-hand margin. This line draws itself relative to page-scroll to guide the reader's eye.
4. **Blueprints Layout**: Glow points (hotspots) on the character figurines project dashed connector lines to align with specific card descriptions.

## 🎬 Animation Techniques

### 1. SplitText Letter Stagger
Text strings are parsed into individual character spans. Each character is rendered inside an overflow-hidden wrapper, animating vertically from `translateY(110%)` to `translateY(0)` with a staggered inline delay:
```typescript
delay = baseDelay + (wordIndex * 3 + charIndex) * 20ms
```

### 2. Magnetic CTAs
Tracks client coordinates relative to the button's center. If the mouse comes within a `120px` radius, the button shifts dynamically towards the cursor:
```typescript
xShift = mouseDeltaX * 0.4, yShift = mouseDeltaY * 0.4
```

### 3. Custom Cursor Follower (Play/Pause)
Hides the default browser cursor (`cursor: 'none'`) inside the video container. Tracks cursor coordinates `(X, Y)` relative to the card and shifts a custom circular SVG button (`translate3d(X - Offset, Y - Offset, 0)`) under the mouse using cubic-bezier transitions.
